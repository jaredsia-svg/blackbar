What this does

Blackbar finds things that look sensitive, shows you every one of them, and covers only the ones you approve. Then it rebuilds the document from scratch so the covered content is gone, not hidden.

Drawing a black rectangle over text in a PDF editor does not remove the text. It stays in the file and can be copied straight back out. That is how redacted court filings and government documents have been un-redacted by readers. Blackbar rasterises each page and builds a new PDF from the pixels, so there is nothing left underneath.

The trade: the exported PDF is an image, so it is no longer searchable or selectable, and the file is larger. Original metadata — author, title, timestamps, revision history — is dropped rather than copied across.
